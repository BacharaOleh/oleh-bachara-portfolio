## 6. Ключові Метрики (Master KPIs)

| Показник | Значення | Опис |
| :--- | :--- | :--- |
| **First-Time-Right (FTR)** | $\ge 98.5\%$ | Точність нарізки дубліката (відкриття замка з 1-ї спроби) |
| **Cycle Time** | $\le 60$ с | Час повного циклу виготовлення ключа |
| **Unit CAPEX** | $\le 25 000$ PLN | Собівартість виробництва апаратного кіоска |
| **System Uptime** | $\ge 99.2\%$ | Надійність роботи мережі edge-контролерів |
| **Точність обробки** | $\pm 0.05$ мм | Прецизійна точність ЧПК-фрезерування металу |
