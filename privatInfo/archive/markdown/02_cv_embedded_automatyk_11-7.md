## Реалізовані проєкти (Projekty)

1. **Роботизація та розпізнавання об'єктів (UR-5 + Sick Camera):**
   - Інтеграція маніпулятора Universal Robots UR-5 із промисловою камерою Sick.
   - Розпізнавання деталей за допомогою комп'ютерного зору, позиціонування та сортування через комунікацію TCP/IP.
   - *Ефект:* збільшення швидкості сортування на 35%.

2. **KasaMobile & SmartShop (Android + Bluetooth + RS232):**
   - Комплексна мобільна система керування касовими апаратами та складом.
   - Реалізація обміну даними через Bluetooth (модуль HC-05) та COM-порт (RS232) для зв'язку з вагами та фіскальними блоками.
   - Сканування 2D/штрихкодів за допомогою Camera API/ML Kit, Clean Architecture, Jetpack Compose.

3. **Розумні гаражні ворота (MQTT + Messenger Bot):**
   - IoT-контролер для дистанційного відкриття/закриття воріт через протокол MQTT за командами з чат-бота Facebook Messenger.

4. **Міжмашинна інтеграція (M2M Production Integration):**
   - Синхронізація роботи двох незалежних виробничих машин через мережевий комунікаційний модуль (TCP/IP + Python + мікроконтролери), повна ліквідація помилок неузгодженості ліній.

5. **Моделювання та регулювання PID у Matlab Simulink:**
   - Розрахунок та оптимізація промислових регуляторів PID, симуляція стійкості систем у реальному часі.

6. **3D-моделювання та адитивне виготовлення на замовлення:**
   - Проектування деталей та корпусів у Blender / CAD, налаштування та друк на 3D-принтерах.
