## 1. Операційні Системи та Embedded Linux

### Платформи та апаратна база:
- **Мікрокомп'ютери:** Raspberry Pi (2, 3, 4, 5, Compute Module 4/CM4), промислові IPC. *(Примітка: фокус на екосистемі Raspberry Pi та промислових Linux-шлюзах).*
- **Експлуатація:** 100% Headless-режим (Debian, Ubuntu Server, Raspberry Pi OS), адміністрування суто через SSH/CLI без графічного інтерфейсу для максимальної економії системних ресурсів.

### Відмовостійкість та промислові стандарти:
- **Захист від знеструмлення (Power-Cut Resilience):** Налаштування `read-only rootfs` через `overlayfs` — захист флеш-пам'яті (microSD, eMMC) від вигорання та пошкодження структури файлової системи при аварійному вимкненні рубильника.
- **Апаратний сторожовий таймер (Hardware Watchdog):** Інтеграція `/dev/watchdog` ядра Linux для автоматичного перезавантаження шлюзу в разі зависання демонів чи паніки ядра.
- **Детермінована адресація портів (udev rules):** Написання правил `/etc/udev/rules.d/` за серійними номерами та Vendor/Product ID для створення постійних статичних симлінків (`/dev/ttyRS485_LINE`, `/dev/ttyRFID_DOOR`), що усуває плутанину після перезавантажень.
- **Systemd-архітектура:** Створення сервісів з політиками `Restart=always`, `RestartSec=3s`, затримками очікування мережі `After=network-online.target` та обмеженням пам'яті через cgroups.
- **Безпека:** Авторизація за Ed25519 SSH-ключами, UFW/iptables (Default Deny), Fail2ban, ізольовані SSH-тунелі (Reverse SSH) для доступу через NAT.

## 2. DevOps, Контейнеризація & Git (CI/CD)

- **Docker:** Multi-stage збірки Dockerfile (мінімізація ваги образів з 1.5 ГБ до <80 МБ для eMMC), розгортання на архітектурах ARM64 (Raspberry Pi) та AMD64.
- **Docker Compose:** Однокомандне підняття повного стеку на об'єкті (`docker compose up -d`), налаштування зв'язку між контейнерами, томи даних (volumes) з WAL-режимом для збереження бази.
- **Docker Hub / Registries:** Публікація та версіонування релізних образів для автоматичного оновлення парку пристроїв.
- **Git & GitHub Actions:** CI/CD конвеєри з автоматичним проходженням лінтерів, тестів та збіркою бінарних артефактів прошивок і контейнерів.

## 3. Промислові Польові Шини та Протоколи (Fieldbuses & Protocols)

- **PROFINET & PROFIBUS:** Практичний досвід налаштування зв'язку у Siemens TIA Portal, робота з файлами конфігурації обладнання GSD / GSDML, обмін даними між ПЛК та периферійними модулями.
- **EtherCAT:** Конфігурація високошвидкісного обміну з серводрайверами та виконавчими механізмами.
- **Modbus RTU & Modbus TCP:** Опитування лічильників енергії, частотників, терморегуляторів. Оптимізація таймінгів міжфреймових інтервалів, мапінг регістрів (Holding/Input), перетворення форматів слів (Big/Little Endian, Float32).
- **RS-485 / RS-232:** Апаратне узгодження лінії (120 Ом), напівдуплексний контроль передачі (DE/RE через ioctl), аналіз завад осцилографом.
- **Wiegand & RFID:** Протоколи Wiegand-26/34, Clock & Data, робота зі зчитувачами безконтактних карт і кодонабірними клавіатурами.
- **CAN bus:** Прийом та фільтрація повідомлень за CAN ID, робота в розподілених рухомих вузлах.
- **TCP/IP Sockets:** Асинхронні клієнти та сервери на базі raw TCP/UDP для нестандартних протоколів обладнання.

---

## 4. Брокери Повідомлень (MQTT)

- **Архітектура:** Патерн Pub/Sub, рівні гарантії доставки QoS 0, QoS 1 (гарантоване підтвердження аварій та RCP), QoS 2.
- **Спеціальні механізми:** Retained Messages (збереження останнього статусу вузла), Last Will & Testament (LWT — автоматичне сповіщення про аварійне відпадання зв'язку), ієрархія топіків із вайлдкардами (`+`, `#`).
- **Eclipse Mosquitto:** Розгортання на Linux Edge шлюзах, ACL (Access Control Lists), шифрування TLS (порт 8883), режим моста (MQTT Bridge) для передачі буферизованих даних у центр.
- **EMQX:** Базові знання кластеризації, веб-панелі моніторингу та Rule Engine для маршрутизації повідомлень.

## 5. Промисловий Комп'ютерний Зір (OpenCV & Vision)

- **Обробка зображень на OpenCV (Python / C++):** Алгоритми аналізу геометрії, пошуку дефектів, локалізації контурів, виправлення перспективних спотворень (Perspective Warp).
- **Промислові камери та оптика:** Робота з камерами (GigE Vision / USB3 Vision), підбір фокусної відстані об'єктивів під робочу дистанцію, глибину різкості (DoF) та роздільну здатність деталей.
- **Освітлення та синхронізація:** Побудова схем освітлення (Backlight для контуру деталей, коаксіальне світло проти бліків металу), камери з Global Shutter, апаратна синхронізація зйомки через опторозв'язані входи GPIO від датчиків положення.

## 6. Промислова Телеметрія, InfluxDB & Вбудована Grafana

- **Time-Series сховища:** InfluxDB (структура вимірювань, оптимізація тегів, політики Retention Policies для стиснення даних), Prometheus (збір системних та апаратних метрик).
- **Grafana & Business Charts:** Комплексні OEE-дашборди (Availability, Performance, Quality), плагіни бізнес-аналітики та діаграм (Apache ECharts, State Timeline).
- **Embedded Grafana (Вбудовування у Веб/MES):** Інтеграція аналітичних панелей Grafana безпосередньо в кастомні інтерфейси (React 19 Canvas) через `<iframe>` у Kiosk Mode з JWT/Service Account автентифікацією та динамічною підстановкою контекстних параметрів обладнання (`&var-device=`).

## 7. Схемотехніка, Проєктування Плат (PCB) та Апаратна Надійність

- **Проєктування друкованих плат (PCB Layout & EDA):** Самостійне розведення плат та створення принципових схем у САПР (KiCad / EasyEDA / Altium): трасування сигнальних та силових кіл, підготовка виробничих файлів (Gerber, BOM, Pick&Place).
- **Захист входів/виходів:** TVS-діоди на сигнальних шинах, поліві самовідновлювані запобіжники PTC, варистори MOV.
- **Захист від переполюсовки:** Схемотехніка ідеального діода на P/N-MOSFET з нульовим падінням напруги.
- **Гасіння індуктивних сплесків:** Діоди Шотткі та RC-снайбери паралельно реле, соленоїдам і замкам.
- **Гальванічна розв'язка:** Оптопари (PC817/TLP281), цифрові ізолятори (TI/ADI), ізольовані трансивери RS-485/CAN.
- **Топологія живлення:** Широкий вхід 9–36V DC, імпульсні Step-Down DC-DC + ультранизькошумні LDO для аналогових кіл, суперконденсатори / танталові ємності для Last-Gasp аварійного збереження при brownout.
- **Діагностичне обладнання:** Осцилографи (аналіз форми імпульсів, шумів живлення), логічні аналізатори (декодування SPI, I2C, UART, Wiegand), прецизійний SMD-монтаж (до 0603/QFP/QFN).
